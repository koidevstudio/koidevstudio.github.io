Privacy Policy

koi-rclone · KOI Dev Studio · Last updated: October 5, 2026

What this app is

koi-rclone is a private, single-user tool. It is used only by its owner, with the owner's own Google account, to upload and organize the owner's own files in their own Google Drive: database backups and promotional videos. It is not offered to the public.

Google user data

The app uses the Google Drive API with the drive.file scope. It can only see and change files that it created itself. It cannot read any other file in the Drive.

  • No data is collected, stored or processed outside the owner's own Google Drive and computers.
  • No data is sold, shared with or transferred to any third party.
  • No data is used for advertising or analytics.

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from Google Account → Third-party connections.
